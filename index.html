The first Mira app
首个 Mira 应用 · 已发布

Mira Harness.

从目标到成果的 AI 任务工作台。告诉 Harness 你要做什么，它会制定计划，调用文件、终端、浏览器和工具逐步执行。

HARNESS / 01

执行有计划，
过程看得见

不只是给出回答，而是把目标拆成可执行的步骤。涉及关键操作时，由你决定是否继续。

  • 计划展示与工具调用
  • 文件修改与命令执行审批
  • 子智能体协作与随时停止
  • 会话保存、恢复与继续
HARNESS / 02

需要的工具，
就在对话旁边

不必在聊天窗口、文件管理器和终端之间来回搬运上下文，任务与工作环境始终在一起。

  • 项目文件浏览、搜索与预览
  • Git 状态与任务变更
  • 集成终端与命令执行
  • 内置浏览器与网页操作
HARNESS / 03

从资料到文档，
不用切换工作现场

直接查看常见办公文档，再配合 AI 与文档插件提取、生成和改写内容。

  • PDF、Word、Excel 与 PPT 预览
  • 文档内容提取与分析
  • 配合插件生成与改写内容
  • 成果保留在当前项目工作区
HARNESS / 04

做好一次，
以后重复运行

把多步任务编排成可复用的工作流，定时执行，并保留每次运行记录和产物。

  • 多步骤工作流编排
  • 定时任务自动执行
  • 运行历史与结果追溯
  • 每次任务产物独立保留

当前内测版本支持 macOS Apple Silicon，Windows 版本正在验收。

From zero to done

三步开始你的第一个任务

不需要学习复杂提示词。配置好模型，选一个项目，然后像交代给同事一样描述你的目标。

01 / INSTALL

下载并启动 Mira

从 GitHub Releases 获取内测版本，安装后打开即可进入 Mira Harness。

02 / CONNECT

配置你的模型

添加在线服务商、自定义兼容端点，或接入本地 Ollama。

03 / CREATE

描述目标，开始执行

添加项目或进入个人工作区，选择模型与权限模式，把任务交给 Harness。
